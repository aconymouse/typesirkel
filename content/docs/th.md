## เริ่มต้นใช้งาน {#start}

typeSirkel ใช้ได้สองที่ และทั้งสองที่ก็คือแอปเดียวกัน

- **บนเบราว์เซอร์** ที่ [sirkel.asia/write](/write/) ไม่ต้องติดตั้งอะไรเลย
- **บนเดสก์ท็อป** สำหรับ macOS 11 ขึ้นไป, Windows 10 ขึ้นไป และ Linux (AppImage หรือ .deb) ดาวน์โหลดได้จาก[หน้ารีลีส](https://github.com/aconymouse/typesirkel/releases)

ครั้งแรกที่เปิด คุณจะเข้ามาที่ **Scratch** ซึ่งเป็นสมุดโน้ตเล็กๆ ที่เก็บไว้ในเบราว์เซอร์ของคุณ เหมาะกับการจดอะไรสั้นๆ ถ้าจะทำงานจริงจัง ให้กด **Open folder** ที่ด้านล่างของแถบด้านข้าง แล้วเลือกโฟลเดอร์บนดิสก์ของคุณ โน้ตทุกอันในนั้นจะเป็นไฟล์ `.md` ธรรมดาที่แอปอื่นก็อ่านได้

การเปิดทั้งโฟลเดอร์บนเบราว์เซอร์ต้องใช้เบราว์เซอร์ที่สร้างบน Chromium เช่น Chrome, Edge, Brave หรือ Arc ส่วน Safari และ Firefox เปิดได้ทีละไฟล์

แอปเดสก์ท็อปยังไม่ได้ลงนาม บน Mac ให้เปิดแอปหนึ่งครั้ง แล้วไปที่ **System Settings → Privacy & Security** แล้วเลือก **Open Anyway** บน Windows ถ้า SmartScreen ขึ้นมา ให้เลือก **More info** แล้ว **Run anyway**

## การเขียน {#writing}

เขียนด้วย markdown ธรรมดาได้เลย typeSirkel จะบันทึกให้เองหลังจากคุณหยุดพิมพ์ไปครู่หนึ่ง และจุดที่มุมล่างซ้ายจะบอกว่าบันทึกเสร็จแล้ว

ที่ด้านล่างของหน้าต่าง คุณสลับมุมมองได้สามแบบ

- **Write** แสดงเฉพาะตัวแก้ไข
- **Split** แสดงตัวแก้ไขกับตัวอย่างคู่กัน และเลื่อนไปพร้อมกัน
- **Read** แสดงเฉพาะตัวอย่าง

**Quiet** ซ่อนทุกอย่าง เหลือไว้แค่ตัวอักษรของคุณ กดอีกครั้ง หรือกด **Cmd/Ctrl + .** เพื่อให้ส่วนอื่นกลับมา

กด **+** ข้างรายการไฟล์เพื่อเริ่มโน้ตใหม่ โน้ตจะเรียงตามโฟลเดอร์ และโน้ตที่คุณเปิดอยู่จะมีเครื่องหมายกำกับไว้

## เมนูสแลช {#slash}

พิมพ์ `/` ที่ต้นบรรทัด หรือหลังช่องว่าง เพื่อเปิดเมนูรูปแบบ พิมพ์ต่อเพื่อกรอง เช่น `/h2`, `/quote` หรือ `/todo` แล้วกด Enter แต่ละรายการจะแสดง markdown ที่มันเขียนให้ คุณจึงค่อยๆ จำไวยากรณ์ได้เองระหว่างใช้งาน

| รูปแบบ | Markdown |
| --- | --- |
| หัวข้อ 1, 2, 3 | `#`, `##`, `###` |
| ตัวหนา, ตัวเอียง, ขีดฆ่า | `**text**`, `*text*`, `~~text~~` |
| รายการแบบจุด, รายการแบบตัวเลข, งาน | `-`, `1.`, `- [ ]` |
| ข้อความอ้างอิง | `>` |
| ลิงก์, รูปภาพ | `[text](url)`, `![alt](url)` |
| โค้ดในบรรทัด, บล็อกโค้ด | `` `code` ``, ```` ``` ```` |
| ตาราง, เส้นคั่น | `| a | b |`, `---` |

ถ้ารูปแบบนั้นมีช่องให้กรอก เช่น ข้อความและที่อยู่ของลิงก์ ให้กด Tab เพื่อข้ามไปช่องถัดไป

## คีย์ลัด {#shortcuts}

| ปุ่ม | ใช้ทำอะไร |
| --- | --- |
| `/` | เมนูรูปแบบ |
| Cmd/Ctrl + S | บันทึกทันที |
| Cmd/Ctrl + O | เปิดโฟลเดอร์ |
| Cmd/Ctrl + B, I, E | ตัวหนา, ตัวเอียง, โค้ดในบรรทัด |
| Cmd/Ctrl + K | ลิงก์ |
| Cmd/Ctrl + F | ค้นหา |
| Cmd/Ctrl + 1, 2, 3 | Write, Split, Read |
| Cmd/Ctrl + J | Quill |
| Cmd/Ctrl + Shift + D | พิมพ์ด้วยเสียง |
| Cmd/Ctrl + . | โหมด Quiet |
| Cmd/Ctrl + P | พิมพ์หรือบันทึกเป็น PDF |

## พิมพ์ด้วยเสียง {#dictate}

กดไมโครโฟนที่มุมขวาล่าง หรือกด **Cmd/Ctrl + Shift + D** แล้วเริ่มพูด คำพูดของคุณจะปรากฏที่เคอร์เซอร์ระหว่างที่พูด เหมาะกับการจดใจความการประชุมไว้ก่อน แล้วค่อยเรียบเรียงทีหลังด้วยตัวเองหรือให้ Quill ช่วย เลือกภาษาที่พูดในแถบเล็ก ๆ ด้านล่าง แล้วกด **Stop** เมื่อเสร็จ

การพิมพ์ด้วยเสียงใช้ระบบรู้จำเสียงที่มากับเบราว์เซอร์ จึงต้องต่ออินเทอร์เน็ต และเบราว์เซอร์จะส่งเสียงไปยังบริการเสียงของตัวเอง ใช้ได้บน Chrome, Edge และ Safari ปุ่มไมโครโฟนจะแสดงเฉพาะที่ที่รองรับเท่านั้น

## โครงร่าง {#outline}

ทุกหัวข้อในโน้ตของคุณจะกลายเป็นจุดแวะบนเส้นทางใต้ **On this page** ในแถบด้านข้าง ขณะที่คุณเขียนหรือเลื่อนหน้า ตัวบอกตำแหน่งเล็กๆ จะเดินตามไปยังส่วนที่คุณอยู่ คลิกจุดไหนก็ได้เพื่อข้ามไปที่นั่น

คุณลากเส้นบางๆ ระหว่างส่วนต่างๆ ของแถบด้านข้างเพื่อเพิ่มหรือลดพื้นที่ของแต่ละส่วนได้ ดับเบิลคลิกที่เส้นเพื่อรีเซ็ตกลับเหมือนเดิม

## Quill ผู้ช่วย AI ของคุณ {#quill}

Quill คือผู้ช่วยเขียนที่อยู่ใน typeSirkel เปิดได้ด้วย **Cmd/Ctrl + J** หรือปุ่ม **Quill** ที่มุมล่างขวา คุณใช้คีย์ของคุณเอง และคีย์จะไม่ออกจากอุปกรณ์ของคุณไปไหน นอกจากส่งไปหาผู้ให้บริการของคุณเท่านั้น

### การเชื่อมต่อผู้ให้บริการ

- **Anthropic** สำหรับ Claude สร้างคีย์ได้ใน [Claude Console](https://platform.claude.com/settings/keys)
- **OpenAI** สำหรับ ChatGPT สร้างคีย์ได้ที่[หน้า API keys ของ OpenAI](https://platform.openai.com/api-keys)
- **OpenRouter** สำหรับโมเดลหลายร้อยตัว รวมถึง Gemini สร้างคีย์ได้ที่ [openrouter.ai/keys](https://openrouter.ai/keys)
- **Ollama** สำหรับโมเดลบนเครื่องของคุณเอง ไม่ต้องใช้คีย์เลย ถ้าใช้บนเบราว์เซอร์ ให้เริ่มด้วย `OLLAMA_ORIGINS=https://sirkel.asia ollama serve`
- **Other** สำหรับบริการใดก็ได้ที่ใช้รูปแบบแชทของ OpenAI วาง base URL และคีย์ของบริการนั้นลงไป

เลือกผู้ให้บริการ วางคีย์ แล้วเลือกโมเดลจากรายการ แอปเดสก์ท็อปเก็บคีย์ไว้ใน keychain ของระบบ ส่วนบนเบราว์เซอร์ คีย์จะอยู่จนกว่าคุณจะปิดแท็บ เว้นแต่คุณจะติ๊ก **Remember on this device**

### การขอให้ช่วย

เลือกข้อความสักช่วง หรือวางเคอร์เซอร์ไว้ในย่อหน้า แล้วเลือกคำสั่ง Continue, Tighten, Fix, Summarize หรือ Translate คุณจะเห็นคำตอบก่อน แล้วค่อยเลือก **Replace**, **Insert** หรือ **Replace all** หรือจะถามด้วยคำพูดของคุณเองแล้วคุยต่อไปเรื่อยๆ ก็ได้

### เขียนหลายไฟล์พร้อมกัน

เมื่อเปิดโฟลเดอร์อยู่ **Brief** ให้คุณอธิบายงานที่อยากได้ ตรวจดูแผนไฟล์ที่ Quill เสนอมา เอาไฟล์ที่ไม่ต้องการออก แล้วปล่อยให้มันเขียนทีละไฟล์ Quill จะไม่เขียนทับไฟล์ที่มีอยู่แล้วเด็ดขาด

## Prompts {#prompts}

**Prompts** ในแถบด้านข้างคือชั้นวางคำสั่งสำเร็จรูป มีทั้งสยองขวัญ แฟนตาซี ข่าวแบบตรงไปตรงมา การเรียบเรียงใหม่ที่ไม่แตะคำพูดอ้างอิงหรือชื่อคนเลย บทความ SEO บทสอน และสตอรีบอร์ด ป้ายเล็กๆ ข้างชื่อใช้สลับภาษาของชั้นวาง

คลิกพรอมต์เพื่ออ่าน **Copy** จะคัดลอกไปไว้ในคลิปบอร์ดให้ใช้กับ AI ตัวไหนก็ได้ **Use in Quill** จะปักพรอมต์นั้นไว้เป็นสไตล์ของทุกอย่างที่ Quill เขียน จนกว่าคุณจะล้างออก

## เขียนร่วมกัน {#share}

กด **Share** แล้วกด **Start sharing** ใครก็ตามที่มีลิงก์จะแก้ไขฉบับร่างไปพร้อมกับคุณได้ และเห็นว่าแต่ละคนกำลังพิมพ์อยู่ตรงไหน ถ้าฉบับร่างเป็นไฟล์จากโฟลเดอร์ของคุณ สิ่งที่คนอื่นแก้จะลงในไฟล์ของคุณทันทีที่เขาพิมพ์

ฉบับร่างที่แชร์ถูกเข้ารหัสแบบต้นทางถึงปลายทาง คีย์อยู่หลังเครื่องหมาย `#` ในลิงก์ ซึ่งเบราว์เซอร์ไม่เคยส่งไปยังเซิร์ฟเวอร์ ตัวรีเลย์จึงทำได้แค่ส่งต่อข้อมูลที่มันอ่านไม่ออก ลิงก์หนึ่งมีคนเข้าร่วมได้สูงสุด 24 คน ห้องที่ไม่มีใครแตะเลย 30 วันจะถูกลบ ทุกครั้งที่แชร์ คุณจะได้ลิงก์ใหม่ และการย้ายไปไฟล์อื่นจะเป็นการหยุดแชร์

## MCP สำหรับ AI agent {#mcp}

typeSirkel มาพร้อมเซิร์ฟเวอร์ MCP ตัวเล็กๆ ที่ให้ Claude Desktop, Claude Code, Cursor หรือไคลเอนต์ MCP อื่นๆ แสดงรายการ อ่าน ค้นหา ดูโครงร่าง และเขียนโน้ตได้ในโฟลเดอร์เดียว โดยไม่เข้าไปยุ่งกับที่อื่นเลย แอปเดสก์ท็อปจะเห็นสิ่งที่พวกมันแก้ทันทีที่เกิดขึ้น

ระหว่างที่แพ็กเกจยังไม่ได้เผยแพร่ ให้ build จาก repository ก่อน

```bash
git clone https://github.com/aconymouse/typesirkel
cd typesirkel/mcp
pnpm install && pnpm build
```

จากนั้นตั้งค่าไคลเอนต์ให้ชี้มาที่มัน เช่น ในไฟล์ config ของ Claude Desktop

```json
{
  "mcpServers": {
    "typesirkel": {
      "command": "node",
      "args": ["/path/to/typesirkel/mcp/dist/index.js", "/Users/you/Notes"]
    }
  }
}
```

## Export {#export}

**Export** ที่มุมล่างขวาให้คุณได้หน้า HTML แบบแยกเดี่ยวที่สะอาดตา ไฟล์ PDF ผ่านหน้าต่างพิมพ์ หรือสำเนาของ markdown โน้ตของคุณเป็นไฟล์ธรรมดาอยู่แล้ว จึงไม่มีอะไรต้องส่งออกเพิ่ม
