## Apakah typeSirkel gratis? {#free}
Ya. typeSirkel gratis dan open source dengan lisensi MIT. Gak ada paket berbayar, akun, atau masa coba. Kalau kamu pakai AI di dalamnya, kamu bayar langsung ke penyedia AI-mu dengan key sendiri.

## Di mana catatanku disimpan? {#storage}
Di disk kamu sendiri. Saat kamu membuka folder, setiap catatan adalah file `.md` biasa di folder itu dan bisa dibuka aplikasi apa pun. Catatan di Scratch tersimpan di penyimpanan browser sampai kamu pindahkan ke folder, jadi hanya ada di browser itu.

## Apakah perlu akun? {#account}
Gak. Buka editornya dan langsung menulis. Gak ada yang memintamu daftar atau masuk.

## Bisa dipakai offline? {#offline}
Aplikasi desktop jalan penuh tanpa internet. Editor web butuh koneksi untuk dimuat, setelah itu tetap jalan di file-filemu. AI butuh internet, kecuali kamu menjalankan model lokal lewat Ollama.

## AI apa saja yang bisa dipakai? {#ai}
Claude lewat Anthropic, ChatGPT lewat OpenAI, ratusan model termasuk Gemini lewat OpenRouter, model lokal lewat Ollama, dan layanan apa pun yang memakai format chat OpenAI. [Dokumentasi](/id/docs/#quill) menjelaskan satu per satu.

## Apakah API key-ku aman? {#keys}
Key-mu tetap di perangkatmu. Aplikasi desktop menyimpannya di keychain sistem. Di browser, key hilang saat tab ditutup, kecuali kamu centang **Remember on this device**. Permintaan langsung dikirim ke penyedia AI-mu, tanpa server typeSirkel di tengahnya.

## Seberapa privat menulis bareng? {#sharing}
Privat. Draf yang dibagikan terenkripsi end-to-end. Key-nya ada di bagian tautan setelah tanda `#`, yang gak pernah dikirim browser ke server, jadi relay cuma meneruskan data yang gak bisa dibacanya. Satu tautan bisa dipakai sampai 24 orang, dan ruang yang gak disentuh selama 30 hari akan dihapus.

## Browser apa yang bisa membuka folder? {#browsers}
Browser berbasis Chromium seperti Chrome, Edge, Brave, dan Arc bisa membuka satu folder utuh. Safari dan Firefox membuka satu file sekaligus. Aplikasi desktop bisa membuka folder di mana saja.

## Bisa dipakai di HP? {#phone}
Bisa, lewat browser. Di HP kamu menulis di Scratch atau membuka satu file, dan sidebar ada di balik tombol menu di atas.

## Gimana cara membantu? {#help}
Kasih bintang di [GitHub](https://github.com/aconymouse/typesirkel), laporkan bug, usulkan prompt, terjemahkan halaman, atau kirim pull request. [Panduan kontribusi](https://github.com/aconymouse/typesirkel/blob/main/CONTRIBUTING.md) menjelaskan caranya.

## Boleh donasi? {#donate}
Boleh banget, makasih. Kamu bisa nyawer lewat Saweria kalau dari Indonesia, atau PayPal dari mana saja. Semuanya ada di [halaman dukung](/id/support/).
